# NEXUS GAMES

A Telegram Mini App + Telegram Bot gaming platform using virtual credits only.

> Virtual credits have no monetary value. Games are for entertainment purposes only. No real-money wagering, deposits, or withdrawals are available.

## Planned structure

- `/apps` — web (Mini App), api, bot, admin
- `/packages` — database, shared, telegram, game-engine, security, ui
- `/infrastructure` — Docker & deployment
- `/docs` — architecture, API, database, security, deployment
